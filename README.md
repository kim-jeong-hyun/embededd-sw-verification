# embededd-sw-verification Portfolio

이 저장소는 임베디드 소프트웨어 검증 역량을 강화하기 위한 개인 프로젝트 저장소 입니다.

각 프로젝트는 실제 SW 개발 프로세스를 기반으로 다음 과정을 포함합니다. 

1. Requirement Specification
2. Sofeware Design 
3. Source Code
4. Unit Test
5. Requirement Tracebility
6. Coverage Analysys
7. Test Automation CI/CD
8. AI Based Test Case Generation
9. Test Report

## Goal

본 저장소의 목표는 단순히 프로그램을 개발하는 것이 아닌

- 요구사항 기반 검증(Requirement-Based Verification)
- 테스트 케이스 설계(Test Case Design)
- 단위 테스트(Unit Testing)
- 테스트 자동화(Test Automation)
- 커버리지 분석(Coverage Analysis)
- AI 기반 테스트 케이스 생성 및 검증

과정을 실제 프로젝트 형태로 수행하여 SW 검증 역량을 향상시키는 것입니다.
