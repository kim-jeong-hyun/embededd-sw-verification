# SWE.6 첫 과제 — IGN 기반 전원 요청 SW 요구사항

| 항목 | 내용 |
|---|---|
| 문서 ID | SW-INPUT-001 |
| 버전 | 1.0 |
| 날짜 | 2026-11-15 |
| 상태 | 첫 과제용 고정 교육 입력 / 제품 기준선 아님 |
| 출처 | PROJECT_KICKOFF.md §6.2에서 분리, 요구사항 내용 변경 없음 |
| 용도 | 학습자가 SWE.6 TC를 설계할 때 사용하는 기준 문서 |

## 1. 대상과 경계

통합된 제어기 SW의 외부 입출력 동작을 검증한다. 내부 함수, 코드 구조, 실제 릴레이와 장치 전원은 검증 대상이 아니다. 이번 과제는 문서 기반 TC 설계와 리뷰이며 실행 가능한 SW는 제공되지 않았다.

## 2. 전제 조건과 인터페이스

| 항목 | 정의 |
|---|---|
| 동작 전제 | SW 전원 공급 및 초기화 완료. 고장·다른 전원 제어 요청·출력 억제 조건 없음 |
| 입력 IGN | SW 외부 입력 지점의 유효한 Boolean 신호. 값은 ON 또는 OFF |
| 출력 PWR_REQ | SW 외부 출력 지점의 Boolean 전원 요청. 값은 ENABLE 또는 DISABLE |
| 시간 기준 t0 | SW 입력 지점에서 IGN 변경이 관찰된 시각 |
| 시간 판정 | 100 ms 이내는 100 ms를 포함함 |
| 시험 환경 가정 | 입력을 설정하고 출력 및 시간을 1 ms 단위로 관찰할 수 있음. 실제 환경 구축·실행은 하지 않음 |

## 3. SW 요구사항

| 요구사항 ID | 요구사항 |
|---|---|
| SWR-IGN-001 | IGN이 OFF에서 ON으로 변경되고 ON으로 유지되면, SW는 t0부터 100 ms 이내(100 ms 포함)에 PWR_REQ를 ENABLE로 설정하고 IGN이 ON인 동안 유지해야 한다. |
| SWR-IGN-002 | IGN이 ON에서 OFF로 변경되고 OFF로 유지되면, SW는 t0부터 100 ms 이내(100 ms 포함)에 PWR_REQ를 DISABLE로 설정하고 IGN이 OFF인 동안 유지해야 한다. |

## 4. 범위와 제약

- 물리 신호의 노이즈·디바운싱·통신 지연은 제외한다.
- 다음 IGN 변경이 100 ms 응답 구간 안에 발생하는 상황, 초기화 중 동작, 고장 처리는 제외한다.
- 유지 동작의 관찰 구간은 학습자가 정하고 선정 근거를 설명한다. 유한한 관찰 구간으로 보장할 수 있는 범위를 구분한다.
- 입력이 불명확하면 임의로 사양을 보완하지 않고 질의와 TC 설계 영향을 기록한다.
- 본 문서의 신호·수치는 교육용이며 실제 제품 또는 기존 EPM 사양으로 적용하지 않는다.
