## 1. 작성 안내

요구사항 문서를 읽고 TC 3~5개를 직접 작성한다. 아래 빈 표를 TC마다 복사하여 사용한다. 요구사항에서 도출한 기대 결과와 본인이 선택한 시험 조건·관찰 구간을 구분하고 선정 근거를 설명한다. 이번 과제에서는 코드를 작성하거나 실행하지 않는다.

## 2. TC-IEC-001

| 필드 | 학습자 작성 내용 |
|---|---|
| TC ID | TC-SWR-IGN-001 |
| TC 제목·목적 | IGN OFF → ON 시 PWR_REQ의 100 ms 이내 ENABLE 전환 및 유지 확인 |
| 검증 수준 | SWE.6 |
| 기준 문서 ID·버전 | SW-INPUT-001 v1.0 (SWE6_IGN_Requirements.md v1.0) |
| 연결 요구사항 ID | SWR-IGN-001 |
| 적용 기법·조건 선정 근거 | 상태 전이 테스트, 입력 신호에 의한 출력 상태 변경 확인 |
| 사전 조건 | IGN = OFF & PWR_REQ = DISABLE, SW 전원 공급 및 초기화 완료, 고장 및 다른 전원 제어 요청, 출력 억제 조건 없음. |
| 시험 환경·관찰 지점 | SW 외부 입력 지점의 IGN이 OFF → ON으로 변경된 시점을 t0로 정의한다. SW 외부 출력 PWR_REQ를 t0부터 t0+10,000 ms까지 양 끝 시점을 포함하여 1 ms 주기로 관찰한다. |
| 입력·실행 절차(순서대로 기재) | 1. IGN을 OFF → ON으로 변경하면서 동시에 출력, 시간 기록을 시작한다.<br>2. IGN을 ON으로 10,000 ms 유지하는 동안 PWR_REQ를 1 ms 주기로 기록한다.<br>3. t0+10,000 ms 시점의 출력을 기록하고 관찰을 종료한다. |
| 기대 결과·Pass/Fail 판정 기준 | 1. t0부터 t0+100 ms(100 ms 포함) 이내 PWR_REQ가 DISABLE에서 ENABLE로 변경되어야 한다.<br>2. PWR_REQ가 ENABLE로 전환된 후에는 시험 종료 시점인 t0+10,000 ms까지, 1 ms 주기로 관찰한 모든 PWR_REQ 값이 ENABLE이어야 한다.<br>3. 두 조건을 모두 만족하면 Pass, 하나라도 만족하지 않으면 Fail로 판정한다. |
| 관찰 시간·선정 근거 | 관찰 주기는 시험 환경의 해상도에 따라 1 ms로 설정한다. 관찰 기간 10,000 ms는 이번 실습에서 시험자가 임의 선정한 구간이다. 유지 여부의 확인 범위는 해당 기간과 관찰 주기로 제한되며, 무기한 유지 및 관찰 시점 사이의 출력 변화는 보장하지 않는다. |
| 우선순위·근거 | High, IGN ON으로 변경되면 전원 제어가 가능해야 하기 때문에 High로 설정 |
| 리뷰 상태 | 승인 |
| 실행 판정 | Not Run |

## 4. 설계 범위와 한계

검증하려는 범위와 이번 TC로 확인할 수 없는 내용을 학습자가 작성한다.

## 5. 제출 후 리뷰

Codex는 제출된 TC의 추적성, 조건 선정 근거, 재현성, 관찰 지점과 판정 가능성을 리뷰한다. 리뷰 승인과 실행 합격은 구분한다. 다음 과제·단계는 학습자의 명시적인 승인 후 진행한다.
